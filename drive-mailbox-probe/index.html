drive-mailbox-probe

drive-mailbox-probe is a private, owner-operated personal test application. One person, the owner, uses it to test how a personal software project can read a very small amount of metadata from that person's own Google Drive. It is not a product, is not offered to the public, and has no customers.

What it is

  • A test tool run by its owner on the owner's own computer, for a limited period.
  • Its user set is very limited: one Google account, which belongs to the owner. No other person is expected to sign in or use it.
  • It has no public sign-up, no other accounts, and no advertising.
  • It is not affiliated with or endorsed by Google.

What it asks Google for

One permission, shown by Google as "See information about your Google Drive files" (https://www.googleapis.com/auth/drive.metadata.readonly). This permission does not allow reading the contents of any file, and does not allow changing, creating, sharing or deleting anything. The Privacy Policy explains what the permission technically allows and what this test actually does: https://leventen.net/drive-mailbox-probe/privacy/
